# logan-mondal-bhamidipaty

Personal website for Logan Mondal Bhamidipaty — <https://logan-mondal-bhamidipaty.com>

The whole site is one hand-built file, [`index.html`](index.html): a pixel-art
flying workshop drifting over Edinburgh, drawn as inline SVG on a single pixel
grid. Press **ascend**.

The previous Jekyll site is preserved on the
[`old-site`](https://github.com/FlyingWorkshop/logan-mondal-bhamidipaty/tree/old-site)
branch. `assets/` is kept so existing deep links (CV, posters) still resolve.
